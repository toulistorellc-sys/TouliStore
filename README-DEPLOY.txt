TOULI STORE — VERCEL DEPLOYMENT

This is a static HTML site. The deploy-ready structure is:
  index.html
  assets/ (all product photos and logo)

IMPORTANT: Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
Do not upload the ZIP as a single file and do not put index.html inside another nested folder.

Vercel settings:
  Framework Preset: Other
  Root Directory: ./
  Build Command: leave empty
  Output Directory: .
  Install Command: leave empty

Then Save and Redeploy. In Vercel, make sure the latest successful deployment is assigned to the domain toulistore.vercel.app.

Images are referenced with relative paths such as assets/mug.jpg. Keep the assets folder beside index.html and preserve filenames/capitalization.
